## Як читати
- **Шляхи до коду** — від кореня репозиторію (`backend/app/...`, `frontend/src/...`).
- **Коди помилок** (`ACCESS_DENIED`, `TOKEN_EXPIRED`…) — стабільні; інтерфейс показує їх переклад (`frontend/src/lib/messages.ts`).
- **Схеми** — у Mermaid (GitHub малює їх сам). Це робочі схеми для команди; схеми для звіту — за UML 2.5.1 у draw.io.

## Як підтримувати
Після кожного етапу: оновити або додати файл процесу, перевірити, що назви маршрутів і таблиць збігаються з кодом,
і додати посилання на тести. Якщо процес змінився — спершу рішення S-xx у журналі, потім цей опис.
